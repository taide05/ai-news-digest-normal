**最后更新:** 2026-06-09
**当前阶段:** v0.6 完成，待规划 v0.7

---

## 一、项目定位

一个本地运行的个人 AI 资讯学习工具。不是资讯推送器，是 **AI 学习导师**——帮用户把表层信息转化为可理解的深度知识。

**用户:** 一个人使用，AI 领域学习者，中文环境，不具备专家级分辨力，需要 AI 辅助理解"这意味着什么"。

---

## 二、终局愿景（v1.0+）

```
用户每天双击快捷方式
  → 自动采集 → 智能聚类 → 企微通知
  → Web 面板阅读 → AI 逐篇深度解读
  → 系统学习用户兴趣 → 个性化推荐
  → 周报/月报总结学习轨迹
```

## 五、标准开发循环（强制流程，不可跳过任何阶段）

**每个版本严格走完 A → B → C → D → T → E → F，T 是强制门禁，F 是收尾归档。**

```
阶段 A: 验收上一版本 ──── 确认上一版功能正常，发现回归bug
    │
    ▼
阶段 B: 代码审计 ──────── 架构+安全+质量+性能审查，修问题
    │
    ▼
阶段 C: 需求规划 ──────── brainstorming + 多视角审查(aesthetic/systems/logic) → spec → plan
    │
    ▼
阶段 D: 开发 ──────────── subagent-driven，逐task实现+审查，TDD
    │
    ▼
阶段 T: 系统测试 🔴门禁── 全量/回归/边界/集成/性能/安全/覆盖率
    │                    任何失败 = 回到 D 修复，T 不过不能进 E
    ▼
阶段 E: 验收 ──────────── 验证所有 v0.x 行为，确认可交付
    │
    ▼
阶段 F: 归档准备 ──────── Cycle Report + PROJECT-OVERVIEW 同步 + 规则审计 + 下一版本种子
```

### 阶段 F: 归档与规则审计

**每个版本完成后的收尾阶段。确保所有决策和规则落地为文档。**

1. **Cycle Report** — 写入 `docs/superpowers/reports/YYYY-MM-DD-cycle-N-report.md`，记录完整的 A→F 过程、测试数、commit 数、关键决策
2. **PROJECT-OVERVIEW.md 同步** — 更新版本路线图、当前阶段、版本历史表
3. **规则审计** — 检查本次循环中产生的新规则是否已写入文档，对话中的规则不算规则
4. **下一版本种子** — 列出候选功能池，供下一轮 C 阶段 brainstorming 使用

### 阶段 T: 系统测试（强制门禁）

**这是整个循环的质量闸门。T 不过，不准进 E。**

| # | 检查项 | 执行方式 | 说明 |
|---|--------|---------|------|
| T1 | 全量测试 | `pytest tests/ -v` | 必须 100% 通过 |
| T2 | 回归检查 | 对比上一版本测试数 | 只增不减，确认无测试被删除 |
| T3 | 边界条件 | 子代理专项检查 | 空输入、超长输入、并发、超时、DB锁 |
| T4 | 集成烟雾 | 子代理 | 启动服务器 → 所有路由 200 → 模板正常 |
| T5 | 性能检查 | 子代理 | N+1查询、大循环、未关闭连接、多余commit |
| T6 | 安全回归 | 子代理 | XSS、SQL注入、SSRF、密钥泄露快速扫描 |
| T7 | 覆盖率 | `pytest --cov` | 对比上一版本，目标持续提升 |
| T8 | 问题修复 | 子代理 | T1-T7 发现的所有问题修复 |

**T 阶段输出:** 测试报告 + 发现问题清单 + 修复记录 → 写入 `docs/superpowers/reports/YYYY-MM-DD-cycle-N-report.md`

### 阶段 D 内部流程

```
每个 task:
  实现子代理 → spec审查 → 代码质量审查 → ✅ → 下一个
```

### 审查视角

| 视角 | 关注点 | 谁负责 |
|------|--------|--------|
| **架构师** | 模块边界清晰、接口设计合理、技术选型正确、扩展性 | spec 合规审查 |
| **工程师** | 代码质量、错误处理、边界条件、测试覆盖、性能 | 代码质量审查 |
| **PM** | 范围控制、优先级、里程碑、风险、依赖 | 主会话协调 |
| **QA** | 测试策略、验收标准、回归风险 | 代码质量审查 |
| **安全** | 数据保护、输入验证、最小权限 | 代码质量审查 |
