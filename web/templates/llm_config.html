LLM 配置

.env 文件中的值为默认值，下方设置会覆盖默认值。修改后需重启应用生效。

提示：
  • DeepSeek: model=deepseek-chat, URL=https://api.deepseek.com
  • Ollama: model=llama3, URL=http://localhost:11434/v1
  • OpenRouter: model=openai/gpt-4o, URL=https://openrouter.ai/api/v1
  • OpenAI 兼容: 任意兼容接口的 model + URL
